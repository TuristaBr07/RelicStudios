# Relic Studios — homologação Render

Branch isolada para validar gratuitamente o MVP administrativo da Relic Studios no Render.

O código da aplicação está empacotado em `relic-studios-render.tgz` somente para simplificar o deploy temporário sem substituir o projeto/site que já existia neste repositório. O Blueprint `render.yaml` cria um Web Service Free e um PostgreSQL Free.

Este ambiente é exclusivamente de homologação. O banco gratuito do Render é temporário e não deve ser tratado como produção definitiva.
